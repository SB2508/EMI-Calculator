# EMI Loan Calculator API

A small backend service that calculates EMI (Equated Monthly Installment) amounts,
full amortization schedules, and the interest saved from a prepayment — the same
kind of lending math a fintech company like Branch runs on top of every loan it issues.

Built with **FastAPI**, **SQLAlchemy**, and **MySQL** (SQLite fallback for local dev),
with a small static frontend to demo it live.

## Why this project

Built as a hands-on way to learn the core mechanics behind lending products —
how a fixed monthly payment splits between principal and interest over time,
and how a single prepayment changes the total interest a borrower pays.

## The math

**EMI formula:**

```
EMI = P × r × (1 + r)^n / ((1 + r)^n - 1)
```

- `P` = principal loan amount
- `r` = monthly interest rate (annual rate ÷ 12 ÷ 100)
- `n` = tenure in months

Each month, part of the fixed EMI pays interest on the *remaining* balance, and the
rest reduces the principal. As the balance shrinks, less of the EMI goes to interest
and more goes to principal — which is why the last EMI is almost entirely principal.

**Prepayment impact** is calculated by re-running the same amortization loop but
subtracting a lump sum from the outstanding balance at a chosen month, then
comparing total interest paid against the original schedule.

## API Endpoints

| Method | Path | Description |
|---|---|---|
| POST | `/calculate/emi` | Returns EMI, total payment, total interest. Logs the calculation to the database. |
| POST | `/calculate/amortization` | Returns the full month-by-month schedule. |
| POST | `/calculate/prepayment` | Returns the revised schedule and interest saved after a lump-sum prepayment. |
| GET | `/history?limit=20` | Returns the most recent calculations run on the API. |

Interactive API docs are auto-generated by FastAPI at `/docs` once the server is running.

## Running locally

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Then open `http://127.0.0.1:8000/static/index.html` for the demo UI, or
`http://127.0.0.1:8000/docs` for the interactive API docs.

By default this uses a local SQLite file (`emi_calculator.db`) so you don't need
MySQL set up to try it. To use MySQL, set an environment variable before running:

```bash
export DATABASE_URL="mysql+pymysql://user:password@host:3306/emi_calculator"
```
